# ターミナルで記号を2回押す必要があるときの確認手順

Nexus Shell チーム · 2026年10月9日 · [English](../terminal-input-check.md) · [中文](../zh-CN/terminal-input-check.md)

日本語または中国語の入力ソースを使用中に、`*`、`:`、`~`、`!` などが時々2回押さないと入力できない場合は、アプリのバージョンを確認してください。[Nexus Shell v1.7.10](https://github.com/viewer12/Nexus-Shell-Releases/releases/tag/v1.7.10) の公式サイト / Homebrew版で、このShift記号の問題を修正しました。すべてのIMEや貼り付けの問題を解決するという意味ではありません。

## 1. バージョンと症状を確認する

**Nexus Shellについて**でバージョンを確認します。公式サイト版はアプリの更新確認または[公式ダウンロード](https://nexusshell.app/ja/?utm_source=github-releases&utm_medium=repository&utm_campaign=first_session_202610)を利用してください。現在のインストーラは[リリース情報](https://nexusshell.app/releases/latest.json)で確認でき、古いDMGのURLを更新先として使い続ける必要はありません。Homebrewでは、導入済みcaskを通常の方法で更新できます。

**Mac App Store版**はApple経由で更新を確認してください。この記事は、同じバージョンが各国のストアに配信済みであることを示すものではありません。両版の購入権利とデータは別管理です。入力の切り分けのために購入元を変えたり、Proを再購入したりする必要はありません。

| 症状 | 次に確認すること |
|---|---|
| 日本語・中国語入力中、Shift記号に時々2回の押下が必要 | 公式サイト / Homebrew v1.7.10の修正と、下記のローカル比較 |
| 同じキーで常に別の記号が出る | 入力ソースと物理キーボードの配列 |
| 手入力は正しいが、貼り付けると変わる | 元の文字列、スマート引用符、実際の改行 |
| パスワード入力中、文字も点も表示されない | 端末では通常エコーが無効になるため、それだけでは入力欠落と判断できない |

## 2. ダミー文字列でローカル比較をする

ローカルのテキストエディタで **Aa 1 ! * : ~** と入力します。これは確認用の文字列であり、shellコマンドではありません。SSHパスワード、秘密鍵、本番のコマンドを使わないでください。

macOSの[キーボードビューア](https://support.apple.com/guide/mac-help/use-the-keyboard-viewer-mchlp1015/mac)で、選択中の入力ソースと修飾キーを確認します。物理配列は異なるため、米国配列のShift操作を前提にしないでください。普段の入力ソースとABCなどのラテン文字入力を比較し、元の入力ソースに戻して差を記録します。

エディタでの確認はローカルの基準にすぎず、リモート端末が受け取る内容の証明にはなりません。更新後も再現する場合は、Nexus Shellだけで起きるか、入力ソースに依存するかを記録してください。説明にはダミー文字列を使い、このサンプルをサーバーのshellへ貼り付けて実行しないでください。

## 3. 貼り付けの問題は分けて確認する

全角コロン `：` とASCIIの `:`、曲がった引用符と直線の引用符は別の文字です。画面上の折り返しと実際の改行も異なり、後者はコマンドを送信・分割することがあります。プレーンテキストにも、以前挿入されたスマート引用符が残っている場合があります。

使用前にコピー元と照合してください。改行や記号を自動で置換したり、内容を理解していないコマンドをAgentに書き換えさせたりして、そのまま実行しないでください。今回のキー入力の修正は、貼り付けたコマンドの内容やサーバーへの影響を検証するものではありません。

## 4. 再現条件を伝え、元の作業に戻る

直らない場合は、アプリのバージョン、導入元、macOS、入力ソース、キーボード配列、期待した文字と実際の**ダミー**文字を伝えてください。ローカルエディタでは正常か、入力ソースを変えると結果が変わるかも有用です。端末の全履歴、サーバー情報を含む画像、パスワード、鍵、ログインのコールバックURLは送らないでください。[サポート窓口](https://nexusshell.app/ja/contact?utm_source=github-releases&utm_medium=repository&utm_campaign=first_session_202610)。

入力できるようになったら[初回利用のチェックリスト](first-session.md)に戻り、権限のある重要でないサーバーで作業を1つ確かめてからProを検討してください。更新やローカル入力の成功だけでは、サーバー作業の確認は完了しません。
