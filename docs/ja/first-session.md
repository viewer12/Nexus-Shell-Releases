# ダウンロード後、最初のサーバー作業を確認する

Nexus Shell チーム · 2026年10月8日 · [English](../first-session.md) · [中文](../zh-CN/first-session.md) · [한국어](../ko/first-session.md)

ログイン手順は**公式サイト / Homebrew版 v1.7.9**が対象です。Apple Silicon Mac、macOS 14.2以降、アクセス権のあるサーバーが必要です。アプリにVPSやサーバーアカウントは付属しません。

## アプリからサインインする

1. Nexus Shellのサイドバーで**メンバーシップ → サインイン**を選びます。アプリが開いたブラウザで認証を終え、Nexus Shellに戻る操作を許可してください。Webサイトだけにログインしても、アプリのログインは完了しません。
2. アプリ内のアカウントとメンバーシップを確認します。待機したままなら、アプリから開始したブラウザの認証を完了するか、アプリからサインインをやり直します。コールバックURLやトークンを共有しないでください。
3. アカウントは表示されるのにプランが古い場合は、メンバーシップの**更新**を選びます。再購入や別アカウントの作成をする前に、現在のアカウントと試用資格を確認します。

対象の新規Webアカウントには、登録時に一度だけ7日間のPro試用が付与されます。カード登録は不要で、終了時の自動課金はありません。再インストールや再ログインで試用期間が再開することはありません。表示される状態と期限を確認してください。無料SSHは個人の非商用利用向けで、SFTP、Docker、監視にはProまたは有効な試用が必要です。

**Mac App Store版：**上記Webアカウント手順は不要です。Appleの購入・復元の流れと表示条件を使ってください。商店版Proは永続ライセンスと自動更新の年額プランを提供し、Agent Bridgeはありません。公式サイト版とは購入権利とデータが別管理で、接続設定は自動移行されません。一方の購入が他方でも有効になるとは約束していません。

## 1台に接続し、1つの作業を確かめる

既存のクライアントを残し、重要でないサーバーを選びます。ホスト、ポート、リモートユーザー名、対応する認証方法を設定してください。**Nexusアカウントとサーバーのログインアカウントは別です。** 新規または変更されたホスト鍵の指紋は、提供元の管理画面や管理者を通じて独立に確認してから信頼します。エラーを消すために検証を無効化しないでください。

`uptime`などの読み取り専用コマンドで、意図したサーバーであることを確認します。接続できない場合は[接続チェックリスト（英語）](https://nexusshell.app/en/guides/fix-mac-ssh-no-route-to-host/?utm_source=github-releases&utm_medium=repository&utm_campaign=first_session_202610)で切り分けます。OpenSSHの別名、外部agent、他のクライアントの設定が自動移行するとは想定しないでください。

- **ファイル：**[テストファイルの手順（英語）](../sftp-transfer-check.md)に従い、自分が書き込める新しいテストディレクトリへアップロードし、Macの別の空ディレクトリへダウンロードして元の値と照合します。SSH接続成功は書き込み権限の証明ではありません。外部編集にはリモートshellなどの追加条件があります。[権限の確認（英語）](../sftp-write-permissions.md)も参照してください。
- **Docker：**[読み取り中心の手順（英語）](../docker-disk-space-checklist.md)でコンテナの状態と範囲を絞ったログを確認します。サーバー側の権限が必要です。試用のためにコンテナやボリュームを削除しないでください。
- **長時間の処理：**切断後も継続する作業を任せる前に、[リモートtmuxの練習（英語）](../remote-jobs.md)を行います。

結果を確認して初めて作業の検証が完了します。ダウンロード、ログイン、試用中の表示だけでは完了ではありません。既存のツールで十分なら使い続けられます。実際の作業に合うと確認できたら、[公式サイト版の永続Pro](https://nexusshell.app/ja/?utm_source=github-releases&utm_medium=repository&utm_campaign=first_session_202610#pricing)を検討してください。

## 困ったとき

日本語・中国語入力中にShift記号が時々2回押さないと入力できない場合は、公式サイト / Homebrew v1.7.10の修正と[入力チェックリスト](terminal-input-check.md)を確認してください。配列、パスワードの非表示、貼り付けの問題を切り分けられます。

アプリとmacOSのバージョン、インストール元、失敗した手順、機密情報を伏せたエラーを添えて[サポートへ](https://nexusshell.app/ja/contact?utm_source=github-releases&utm_medium=repository&utm_campaign=first_session_202610)。SSHパスワード、秘密鍵、コールバックURL、トークン、端末の全履歴は送らないでください。スクリーンショットのホスト名、ユーザー名、無関係なファイルにも注意してください。
