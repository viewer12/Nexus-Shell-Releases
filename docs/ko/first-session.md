# 다운로드 후 첫 서버 작업 확인하기

Nexus Shell 팀 · 2026년 10월 8일 · [English](../first-session.md) · [中文](../zh-CN/first-session.md) · [日本語](../ja/first-session.md)

로그인 단계는 **웹사이트 / Homebrew 버전 v1.7.9**를 기준으로 합니다. Apple Silicon Mac, macOS 14.2 이상, 접근 권한이 있는 서버가 필요합니다. 앱에 VPS나 서버 계정이 포함되는 것은 아닙니다.

## 앱에서 로그인 완료하기

1. Nexus Shell 사이드바에서 **멤버십 → 로그인**을 선택하세요. 앱이 연 브라우저에서 인증을 마친 뒤 Nexus Shell로 돌아가는 동작을 허용합니다. 웹사이트에만 로그인해도 앱이 로그인되는 것은 아닙니다.
2. 앱 안의 계정과 멤버십 상태를 확인하세요. 계속 대기 중이면 앱에서 시작한 브라우저 인증을 완료하거나 앱에서 로그인을 다시 시작합니다. 콜백 URL이나 토큰을 공유하지 마세요.
3. 계정은 표시되지만 플랜이 이전 상태라면 멤버십의 **새로고침**을 선택하세요. 다시 구매하거나 다른 계정을 만들기 전에 현재 계정과 체험 자격부터 확인합니다.

자격을 충족하는 웹사이트 신규 계정에는 가입 시 한 번만 7일 Pro 체험이 부여됩니다. 카드 등록이 필요 없고 종료 시 자동 결제되지 않습니다. 재설치나 재로그인으로 체험 기간이 다시 시작되지는 않습니다. 실제 표시되는 상태와 만료 시간을 확인하세요. 무료 SSH는 개인 비상업용이며, SFTP·Docker·모니터링에는 Pro 또는 유효한 체험이 필요합니다.

**Mac App Store 버전:** 위 웹사이트 계정 단계는 건너뛰고 Apple 구매·복원 절차와 표시 조건을 따르세요. 스토어 Pro는 평생 이용권과 자동 갱신 연간 구독을 제공하며 Agent Bridge는 포함하지 않습니다. 웹사이트 버전과 구매 권한·데이터를 별도로 관리하고 연결 설정도 자동 이전되지 않습니다. 한쪽 구매가 다른 버전에 자동 적용된다고 약속하지 않습니다.

## 서버 하나에 연결하고 작업 하나를 확인하기

기존 클라이언트를 유지한 채 중요하지 않은 서버를 선택하세요. 호스트, 포트, 원격 사용자 이름, 지원되는 인증 방식을 입력합니다. **Nexus 계정과 서버 로그인 계정은 다릅니다.** 처음 연결하거나 호스트 키 지문이 바뀌었다면 제공업체 관리 화면이나 관리자에게 별도로 확인한 뒤 신뢰하세요. 오류를 없애려고 호스트 검증을 끄지 마세요.

`uptime` 같은 읽기 전용 명령으로 의도한 서버인지 확인하세요. 연결에 실패하면 [연결 점검표(영문)](https://nexusshell.app/en/guides/fix-mac-ssh-no-route-to-host/?utm_source=github-releases&utm_medium=repository&utm_campaign=first_session_202610)를 참고합니다. OpenSSH 별칭, 외부 agent, 다른 클라이언트의 설정이 자동으로 이전된다고 가정하지 마세요.

- **파일:** [테스트 파일 안내(영문)](../sftp-transfer-check.md)에 따라 자신이 쓸 수 있는 새 테스트 디렉터리에 올린 뒤 Mac의 다른 빈 디렉터리로 내려받아 원본 값과 비교합니다. SSH 연결 성공이 파일 쓰기 권한을 보장하지 않습니다. 외부 편집에는 원격 shell 등 추가 조건이 있으므로 [권한 점검(영문)](../sftp-write-permissions.md)을 확인하세요.
- **Docker:** [읽기 중심 점검표(영문)](../docker-disk-space-checklist.md)로 컨테이너 상태와 범위를 제한한 로그를 확인하세요. 서버 계정의 권한이 필요합니다. 체험을 위해 컨테이너나 볼륨을 삭제하지 마세요.
- **오래 걸리는 작업:** 연결이 끊겨도 계속되어야 하는 작업을 맡기기 전에 [원격 tmux 연습(영문)](../remote-jobs.md)을 진행하세요.

결과를 확인해야 작업 검증이 끝납니다. 다운로드·로그인·체험 배지 표시만으로 서버 작업을 완료한 것은 아닙니다. 기존 도구로 충분하면 계속 사용해도 됩니다. 실제 작업에 맞는지 확인한 뒤 [웹사이트 평생 Pro](https://nexusshell.app/ko/?utm_source=github-releases&utm_medium=repository&utm_campaign=first_session_202610#pricing)를 검토하세요.

앱과 macOS 버전, 설치 경로, 실패한 단계, 민감한 정보를 가린 오류를 포함해 [지원 문의](https://nexusshell.app/ko/contact?utm_source=github-releases&utm_medium=repository&utm_campaign=first_session_202610)를 남기세요. SSH 비밀번호, 개인 키, 콜백 URL, 토큰, 전체 터미널 기록은 보내지 마세요. 스크린샷의 호스트 이름·사용자 이름·관련 없는 파일도 확인하세요.
